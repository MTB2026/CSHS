# CSHS
A Cybersecurity text game. More updates will come soon.

# FEATURES:
- Hack 2 distinct networks
- Buy tools from the Dark Pool to make hacking easier
- Check your tools inventory, available targets and hacked targets
- You can check cost of targets, tools and rewards for hacked targets
- (NEW) A trace meter which goes up with every hacked target or fail

# UPDATES:
- Implemented a trace meter which goes up with every hacked target or fail
- Added a new tool to the Dark Pool that reduces traces by 35% for 1000 VCoins
