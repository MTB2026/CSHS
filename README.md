# CSHS
A Cybersecurity text game. More updates will come soon.

# FEATURES:
- Hack 10 distinct networks with the tenth being the win condition
- Buy 12 different tools from the Dark Pool to make hacking easier
- Check your tools inventory, available targets and hacked targets
- You can check cost of targets, tools and rewards for hacked targets
- A trace meter which goes up with every hacked target or fail
- 6 different minigames to hack a target
- Random hacker police events to defend from (Uses the aforementioned 6 minigames)
- Save file data, can load and save data. Data is lost upon losing or winning
- 1 hour time limit to complete the game. If the timer runs out, you lose

# UPDATES:
- Increased the number of targets from 2 to 10. The last target wins the game
- 6 logic minigames that are used in both target hacking and hacker police defense
- Hacker police defense minigames that happen randomly during your game
- A time limit of 1 hour to complete the game
- Save files if you want to save your progress
- Changed the structure from global variables to being passed by parameter, should increase efficiency of the code and make debugging/updating much easier (Did however use a global variable for the last function)
